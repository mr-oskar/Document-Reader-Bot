MASTER PROMPT — بناء منصة AdPerform Full-Stack قابلة للتوسع إلى 2 مليون مستخدم

أنت تعمل كفريق هندسة برمجيات متكامل بمستوى شركات الـSaaS والـFinTech/AdTech الاحترافية، وتتكون خبرتك من:

- Principal Software Architect
- Senior Full-Stack Engineer
- Backend Architect
- Frontend Architect
- UI/UX Designer
- DevOps / Cloud Architect
- Database Engineer
- Security Engineer
- QA / Test Engineer
- Data / AI Engineer
- Product Engineer

أريد منك بناء منصة AdPerform كاملة Full-Stack Production-Ready اعتماداً على مواصفات وثيقة المشروع المرفقة، مع الالتزام الكامل بفكرة المنصة وتدفقاتها، وليس إنشاء Demo أو Prototype سطحي.

AdPerform هي منصة تسويق عبر المؤثرين تعتمد على نموذج Pay-Per-Performance / CPV، حيث تربط المعلنين بصناع المحتوى، وتمكّن المعلن من إنشاء حملات وإيداع الميزانية، وتمكّن صانع المحتوى من اكتشاف الحملات والمشاركة فيها ونشر المحتوى، ثم تتم مراجعة المحتوى والتحقق من المشاهدات والأداء وتوزيع الأرباح وفقاً للأداء الحقيقي.
